Allows the entry and maintenance of bicycles including specifications and maintenance and provides a interactive list of bikes via a shortcode. 

== Description ==

= Steve's Bike Maintenance =  plugin provides the ability to add bicycles, their specification and maintenance records.  I also registers a shortcode 
[sbm-bike-list] which can be placed on pages and will render an interactive list of bikes.

Each bike can have details such as an image, serial number, make, model, status and purchase date.  Specification records can be added for a bike to track
parts, standards or measurements for that bike.  Likewise maintenance records can be added to track what work has been done on a bike for a given
date and mileage.

== Installation ==

This plugin is currently only installable via a zip file.

1. Place a copy of the wp_steves_bike_maintenance.zip file in a directory
2. Via the WordPress plugins admin page, choose Add New Plugin
3. On the Add Plugin page, choose "Upload Plugin" and then "Choose File"
4. Browse to the zip file and select it
5. Choose "Install Now"
6. Once the plugin is installed, activate it.  The activation will create the appropriate tables and initial data.

== Frequently Asked Questions ==

= When are the tables deleted? =

The tables are deleted upon an uninstall of the plugin.
